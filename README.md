# ❌⭕ Tic Tac Toe Game

A responsive and interactive Tic Tac Toe game created using **HTML**, **CSS (Tailwind CSS)**, and **JavaScript**.

---

##  About The Project

This project marks a significant milestone in my web development journey as it is my **first vanilla JavaScript project built entirely from scratch** without relying on tutorials or courses—just using my mind logic and my problem-solving skills and I use AI to solve and find the errors.

###  The Core Logic
The highlight of this project is the custom algorithm designed to detect wins or draws dynamically across rows, columns, and diagonals and it can use in matrixes biger than 3x3 and that by adding some adjustments.

---

##  Features

- **Dynamic Turn Switching:** Visual indicators showing whether it's Player X or Player O's turn.
- **Win & Draw Detection:** Instant verification after every move.
- **Score Tracker:** Live updates for Player X, Player O, and Draws with CSS animations.
- **Game Reset:** Clear board and restart anytime with a single click.
- **Responsive Interface:** Styled for desktop and mobile viewports.

---

##  Built With

- **HTML5** - Structure and layout
- **Tailwind CSS** - Styling and layout responsiveness
- **JavaScript** - DOM manipulation and custom game logic
